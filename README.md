# API-Integration-
This project demonstrates API integration using JavaScript Fetch API. It fetches random data from a public API and displays it dynamically on the UI. It also includes loading indicators and proper error handling for better user experience.

# GitHub Profile Finder

## Description
A simple web application that fetches GitHub user profile data using GitHub API.

Users can search by username or GitHub profile URL.

---

##  Features
- Search GitHub users
- Fetch API integration
- Display profile data (avatar, name, bio, stats)
- Loading state
- Error handling
- Enter key support

---

## Tech Stack
- HTML
- CSS
- JavaScript (Fetch API)

---

## ▶️ How to Run
1. Open project folder
2. Open `index.html`
3. Enter username or URL
4. Click search
